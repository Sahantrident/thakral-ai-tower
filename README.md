# Thakral AI Tower

Interactive executive AI briefing for Thakral Group: a 14-floor tower, one idea per floor, guided by NOVA.

**Live:** https://sahantrident.github.io/thakral-ai-tower/

## Ask NOVA (live agent)
- Open with the **Ask NOVA** button, a click on NOVA, the button on any slide, or the **A** key.
- Talks to the `Thakral-AI` agent in Microsoft Foundry (`proj-copilot`) over the Responses protocol.
- Sign-in with Microsoft Entra ID (app registration `Thakral AI Tower`, client ID `1533e439-4b7f-46fb-94d7-6bd0d78d8b5e`). Only people with access to the Foundry project can chat. No keys or secrets are stored in this repo.
- Voice: 🎙️ for a single spoken question, **Start voice call** for hands-free back-and-forth. Uses the browser's speech features (best in Microsoft Edge or Google Chrome).
- The agent's mail tool is always declined from this page.

## Presenting keys
Arrows to move floors · N notes · F full screen · Esc back · A ask NOVA

Simulated scenes use fictional sample data. Live answers are decision support, not financial advice.
